# HCM Lite Frontend

A responsive, browser-based Human Capital Management dashboard for the Saylani Hackathon project.

## Run it
1. Extract `HCM-Lite-Frontend.zip`.
2. Open the `public` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

No installation is required for this frontend demo.

## Features
- Dashboard with workforce metrics, attendance chart, recent activity and leave requests
- Employee directory with search, department filter and add-employee dialog
- Attendance overview and check-in demo action
- Leave request review with approve/reject interactions
- Payroll overview
- Announcements and activity log
- Responsive layout for desktop and mobile

## Important
This is a frontend demo. Data is held in browser memory and resets when the page is refreshed. Authentication, database persistence, real payroll, attendance APIs and role-based permissions need a backend connection. The example dashboard includes sample UI records for demonstration.
